# Usta - Hunarmand Portfoliyo Sayti

An'anaviy hunarmand usta uchun klassik uslubdagi portfoliya veb-sayti.

## Xususiyatlari:

- 🌓 **Kunduzi / Tungi rejim** - klassik issiq ranglarda ikkala rejim ham mavjud
- 🎨 **Klassik dizayn** - yog'och va tuproq ranglarida, serif shriftlardan foydalanilgan
- 📱 **To'liq moslashuvchan** - barcha qurilmalarda (telefon, planshet, kompyuter) yaxshi ko'rinadi
- ⚡ **Tez va yengil** - hech qanday katta kutubxonalar ishlatilmagan
- 🖼️ **Rasmlar bilan boyitilgan** - ustaxonaning haqiqiy ko'rinishini aks ettiruvchi rasmlar

## Bo'limlar:

1. **Bosh sahifa** - asosiy ma'lumotlar va statistika
2. **Biz haqimizda** - ustaning tajribasi va tamoyillari
3. **Xizmatlar** - taklif qilinadigan barcha xizmat turlari
4. **Ishlar** - bajarilgan loyihalar galereyasi
5. **Mijozlar fikri** - oldingi mijozlarning izohlari
6. **Aloqa** - bog'lanish uchun ma'lumotlar va forma

## Ishga tushirish:

Sayt ochish uchun `index.html` faylini brauzerda oching yoki mahalliy server orqali ishlating:

```bash
python3 -m http.server 8000
```

Keyin brauzerda `http://localhost:8000` manziliga kiring.
